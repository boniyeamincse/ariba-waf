First-time setup

Generate a one-time enrollment token from your project directory:

docker compose exec -T management-api /ariba -db /data/db/ariba.db -enrollment-token

Keep the token private; it expires in ten minutes. Using an API client, obtain a CSRF token from /api/v1/auth/csrf, then enroll through /api/v1/setup/enroll. Enrollment creates the first Admin; sign in through /api/v1/auth/login afterward. Retain cookies and send the configured Origin and CSRF token on mutations.

Enrollment closes after the first Admin is created. Existing accounts can use the login API directly.
